## 2.1 Positioning

Noesis sits at the intersection of four research threads: (i) semantic memory hierarchies for cognitive agent architectures, (ii) capability-based security for multi-agent orchestration, (iii) deterministic reproducibility of LLM pipelines, and (iv) open software engineering benchmarks runnable on commodity edge hardware. Each thread has a rich individual literature — §2.2 cites the closest antecedents — but no prior system closes all four simultaneously, a fact that Table 2.1 makes explicit.

The closest individual antecedents to each contribution are, for C1, MemGPT [10] (two-tier paged memory, but semantic tiers not enforced) and ACT-R [11] / SOAR [12] (cognitive layers, but not LLM-agent-native with a Critic promotion gate). For C2, seL4 [13] and Capsicum [14] provide the MAC kernel semantics (60-year lineage from Dennis–Van Horn [15]), but Noesis is the first agent system we are aware of that ports the AND-mask spawn-mint pattern to the multi-agent LLM setting. For C3, Dodge et al. [8] document LLM nondeterminism and propose seed controls, but they do not determinise the orchestration layer or publish a 100-run bit-exact manifest.

## 2.3 Takeaway from the Comparison

Table 2.1 makes the vacuum explicit: each prior system is missing at least two of the three Noesis contributions C1/C2/C3. Most systems are missing all three. LangChain has a flat memory, an allowlist-only capability model, no determinism manifest, and no bundled laptop-first benchmark. AutoGen has no MAC token and no determinism. CrewAI has neither memory tiers nor a MAC kernel nor a reproducibility harness. SWE-bench baselines — while gold-standard for repository-level tasks — have no multi-agent topology, no capability model, no memory model, and no bit-exact manifest. Noesis is therefore the first system, to our knowledge, that simultaneously ships a 6-tier memory with a Critic gate, an AND-mask MAC spawn mint, and a 100-run SHA-256 manifest proving orchestration determinism on a laptop-first benchmark corpus.
