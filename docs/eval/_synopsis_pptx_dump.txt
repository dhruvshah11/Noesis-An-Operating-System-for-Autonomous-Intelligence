  shape 20 name='Text 17' type=AUTO_SHAPE (1) :: Existing limitation:
  shape 21 name='Text 18' type=AUTO_SHAPE (1) :: Framework-level access control; no formal capability inheritance model at the agent spawn boundary.
  shape 22 name='Text 19' type=AUTO_SHAPE (1) :: Research gap:
  shape 23 name='Text 20' type=AUTO_SHAPE (1) :: Limited kernel-level capability isolation and deny-first enforcement for spawned sub-agents.
  shape 25 name='Text 22' type=AUTO_SHAPE (1) :: NOESIS approach → AND-mask capability token inheritance with typed PermissionDenied  (C1)
  shape 29 name='Text 26' type=AUTO_SHAPE (1) :: Deterministic Execution
  shape 30 name='Text 27' type=AUTO_SHAPE (1) :: Existing limitation:
  shape 31 name='Text 28' type=AUTO_SHAPE (1) :: Stochastic LLM sampling makes exact replay difficult across identical inputs without explicit seeding.
  shape 32 name='Text 29' type=AUTO_SHAPE (1) :: Research gap:
  shape 33 name='Text 30' type=AUTO_SHAPE (1) :: Cannot guarantee reproducible execution traces, complicating debugging, auditing, and regression testing.
  shape 35 name='Text 32' type=AUTO_SHAPE (1) :: NOESIS approach → Fixed-seed deterministic orchestration with immutable audit trace  (C2)
  shape 39 name='Text 36' type=AUTO_SHAPE (1) :: Agent Lifecycle Control
  shape 40 name='Text 37' type=AUTO_SHAPE (1) :: Existing limitation:
  shape 41 name='Text 38' type=AUTO_SHAPE (1) :: Workflow-level orchestration without kernel-level spawn, join, checkpoint, or resume primitives.
  shape 42 name='Text 39' type=AUTO_SHAPE (1) :: Research gap:
  shape 43 name='Text 40' type=AUTO_SHAPE (1) :: Limited recovery mechanisms for multi-step workflows interrupted by transient failures.
  shape 45 name='Text 42' type=AUTO_SHAPE (1) :: NOESIS approach → Kernel-level lifecycle hooks: spawn / join / checkpoint / resume  (C2+C3)
