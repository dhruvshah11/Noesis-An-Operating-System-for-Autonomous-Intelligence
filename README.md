## 🧠 Why Noesis?

Most "AI agent" repositories are a thin `requests.post()` wrapper around a single chat-completion call, a context-window away from catastrophic drift, and locked to one LLM provider. **Noesis is an operating system for autonomous intelligence — not a script, not a notebook, not a weekend hack.**

It is the first systems-AI project that brings OS-grade primitives to agentic workloads: **scheduled processes (agents), protected memory (6 tiers + capability gates), I/O controllers (tool registries with MAC), kernel-mode observability, and a userspace dashboard** — while publishing fully reproducible Pineau benchmarks with Efron BCa confidence intervals and McNemar significance testing against 4 LLM backends.

| You need… | Noesis delivers it | Section |
|---|:---:|---|
| Typed 12-agent roster with role-specialised contracts | ✅ C2 | [🧘 Sanskrit Roster](#-%EF%B8%8F-12-agent-sanskrit-roster-c2) |

| 6-tier Sanskrit memory with Atkinson–Shiffrin promotion + determinism 450/450 SHA-256 | ✅ C3 | [🧠 T1→T6 Memory](#-%EF%B8%8F-memory-6-tiers-atkinson%E2%80%93shiffrin-c3) |

### End-to-end request lifecycle (8 steps)

```text
 👤 User submits goal in Dashboard
       │
 1. HTTPS POST /v1/runs → FastAPI JWT + C1 middleware
       │
 2. 🧘 Manan (Planner) splits goal → ExecutionPlan: 12 agent nodes, Kahn topological, cycle-detected,
       memory_agent popped/restored to prevent Planner bleed → pass to 📋 Kriyakari (Executor)
       │
 3. Scheduler dispatches parallel: Darshak (Analyst) + Anveshak (Researcher) fan out
       │
 4. Every tool call AND every spawn → KERNEL CAPABILITY GATE 5-STAGE HMAC (C1):
       split → const-time MAC-SHA256 cmp → Pydantic parse → TTL monotonic → caps/deny masks
       │   ✅ PASS → dispatch; ❌ DENY → PermissionDenied(caps_missing=…) with audit log
       │
 5. Paalak (Memory Bus) applies promotion T1→T6 per write; any_read synthesises 6-tier join
       │
 6. Vidya (Coder) applies AST-safe CodingPatchReport; Parikshak (Tester) runs harnessed claim suites
       │
 7. Samanyaka (Synthesizer) + Vivechak (Critic) 5-axis rubric → { signoff | replan | reject }
       │
 8. Nirikshak (Supervisor) appends attestation → kernel writes TaskExecution → Dashboard websocket
       ▼
 👤 Dashboard auto-rotates Bench Hub tabs; sonner toast; Tailwind transitions; JSON + Prometheus flush
```

## 🛡️ Security · C1 MAC + HMAC 5-stage

All per-agent capability tokens use HMAC-SHA256 with a server-side secret `NOESIS_CLAIM_SUITES_HMAC_SECRET` (never committed, never logged, structlog regex-scrubbed on keys matching `*KEY*`, `*SECRET*`, `*TOKEN*`, `*PASSWORD*`).

### 5-stage validation pipeline (atomic)
```text
 STAGE 1 · SPLIT — token = "v1.<base64_payload>.<base64_mac>"
         │    reject malformed w/ 401 (never leak token contents)
 STAGE 2 · CONSTANT-TIME HMAC COMPARE — hmac.compare_digest(local_mac, token_mac)
         │    NO early-exit strings — thwarts timing oracles
 STAGE 3 · PYDANTIC PARSE — payload json → CapabilityToken(ops: set[CapabilityOp], targets, ttl_monotonic, sub, scope, nonce)
         │    extra='forbid' — rejects unknown fields (postel's law inverted)
 STAGE 4 · TTL MONOTONIC CHECK — token.ttl_monotonic ≥ time.monotonic()
         │    (prevents clock-drift replay between kernel replicas)
 STAGE 5 · CAPS ∩ DENY MASKS — (allowed = token.ops ∩ cfg.caps_allow) - cfg.caps_deny
         ▼
         ✅  DISPATCH   (all 5 pass)
         ❌  PermissionDenied(caps_missing=…, audit_id, stage=2|3|4|5)  (any fail)
```

**DEV_LOCAL_CAPABILITY_TOKEN guard (localhost only):** in [bench.ts](file:///C:/Users/dhruv/Downloads/ASTRAOS/frontend/src/lib/api/bench.ts) the short-circuit `isLocalDevBase` is restricted strictly to `localhost`, `127.0.0.1`, and `::1` — **it never fires on public hosts.**
